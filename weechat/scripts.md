These days, installing scripts is super easy.  First, you will need to enable script download within WeeChat with the following command:

```
/script enable
```

Next, we'll go over the most common and useful scripts currently available as of WeeChat version 4.9.0.

# `highmon.pl`
Adds a highlight monitor buffer.
[Link](https://weechat.org/scripts/source/highmon.pl.html/)

# `grep.py`
Search regular expression in buffers or log files.
[Link](https://weechat.org/scripts/source/grep.py.html/)

# `colorize_nicks.py`
[Link](https://weechat.org/scripts/source/colorize_nicks.py.html/)
Use the weechat nick colors in the chat area and command line.

# `autosort.py`
[Link](https://weechat.org/scripts/source/autosort.py.html/)
Automatically keep buffers grouped by server and sorted by name. 

# `go.py`
[Link](https://weechat.org/scripts/source/go.py.html/)
Quick jump to buffers.
